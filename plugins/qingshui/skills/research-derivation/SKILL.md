# 事件研究推导（Research Derivation）

与 `expected-gap` / `divergence-mining` 同族。那两个 skill 是「主体/维度的预期差」，本 skill 是「一条新闻/公告/事件能不能推出新的一层（二阶导 signal）」。

## 定义（硬约束）

二阶导 = 事件背后的一次研究推导，推导出的那一层才能转成 signal。**先写表面句（标题、新闻表面、水平值），目的是删掉它**。signal 只存「删完之后、且相对已有水位是新的一层」的那一句。
- 预期差不是「实际值 − 一致预期」，是状态演进 / 边际变化；基线是库里已有的披露与判断台账，不是卖方一致预期。
- 没有新的一层 = 合格的空结果，不是失败。禁止为凑一句而编一层。

## 触发

用户给一条新闻/公告/事件，问「有没有二阶导」「是不是新的一层」「能不能形成 signal」，或要求把一条事件推导成信号。

## 五步推导（缺一步就不落 signal）

1. **已有水位（先前状态）** —— 先查该主体已有的判断/观察/信号，不靠模型自己说「新」。旧状态**只能引用已有水位**；水位里没有的，不得写「原先」「原来」或「从A向B」。
2. **落地形式（landing form）** —— 必须是**原文里点名的一种形式**（如「北证50ETF」是基金形式）。不同形式是不同的传导，不并成一条泛泛的「利好」。结果词（盈利改善/销售增长/经营范围/商业化）不算形式。
3. **传导（transmission）** —— 哪条通道变了。例：基金 → 申购资金按指数进成分股 = 原先没有的资金入口；配售 → IPO 资金须持股市值。
4. **主体与方向** —— 主体必须是原文出现的名字。禁「政策主题/风险事件/公司/上市公司」。
5. **证伪（falsify）** —— 写得出证伪，或标「依据不足」。结论不能只是标题。

金句样例（无水位时也能过门）：`北交所新添指数基金入口。北证50ETF若落地，申购资金按指数进入成分股，这是原先没有的资金注入。` 证伪：ETF 不批或没有净申购则改号。

## 硬禁令

- 禁止关键词兜底：推不出新的一层就写空，不为命中放宽标准。
- 纯行情快讯（涨停/跌超/指数涨跌）没有制度或机制线索 = 完成的空推导，直接写空，不调用模型。
- 弱关键词命中（订单/政策/风险/项目开工）与「调研/订单交付」这类必须为空——要么推出新的一层，要么空。
- 落地形式不在原文、或「从A向B」的 A 不在原文/水位里，直接拒，不给改稿机会。
- 结论句必须**原样包含落地形式这几个字**（连续出现），换一种说法就当作没落地。
- 已入库的二阶导句子不被后来的弱句子覆盖；同一形式复用同一句，不复读。

## 工具顺序

1. 取原文：`mcp__qingshui_data__get_event_detail(event_id)`；只有 EV 编号时用 `mcp__qingshui_data__fetch_evidence(EV:…)`。
2. 查水位：`mcp__qingshui_data__history_findings(subject=主体)` 取已有判断/观察时间线与当前水位。冷启动/补漏用 `mcp__qingshui_data__semantic_search`，不能替代查水位。
3. 主体是股票时，按需 `mcp__qingshui_data__get_stock_profile` / `get_kline` 看方向是否已被定价。主体是板块/制度（如北交所）则跳过。
4. 结论能落到证据：`mcp__qingshui_data__fetch_evidence(EV:…)`。

## 输出

- 结论段只留过了删句的句子；写不出新的一层就写「没有新的一层」。
- 每条判断带一句证伪，或标「依据不足」。
- 落地形式原样出现在结论里。
- 引用段在期间 / 口径 / 单位上支撑结论。

## 判断沉淀

与 `divergence-mining` 的沉淀段对齐：分析前先 `history_findings`；过了删句、相对水位是新的、写得出证伪时 `write_finding`（kind 用 `new_event` / `progression` / `association`）；句级锚点 `write_observation`。只复述表面句的，不落笔。

## 与生产门禁对齐

生产入库的信号是同一套标准在批量流水线里执行的，见 `backend/app/signals/research_derivation.py`。交互分析结论要与它一致：落地形式、传导、证伪、旧状态只引水位，逐条对得上，才不至于交互说「新」而信号板写不进去。
