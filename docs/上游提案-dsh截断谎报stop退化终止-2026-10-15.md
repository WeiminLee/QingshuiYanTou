# 上游提案：pjlab 网关限流下「截断补全 + 谎报 stop」导致 agent 中途静默终止

> 日期：2026-10-15　提交方：清水投研（QingshuiYanTou）　状态：评审材料（未改动 dsh 任何文件）
> 本文仅整理证据与可选方案，供 dsh 上游（deepseek-ai/dsh）评审决策，不作为本仓库的修复实现。

## 1. 问题陈述

在 pjlab 网关限流/负载场景下，LLM 补全可能被**截断**，但完成事件仍上报
`stopReason: "stop"`（谎报正常停止）。此时若补全内容恰好**只有思维链块（reasoning/thinking）、
零 text、零 tool-call**，agent 循环会将其判定为**正常完成**并结束对话——用户只看到一句
中途汇报，没有任何续跑、重试或错误提示。对评测/取证场景，这是**静默的数据损失**。

## 3. 与现有设计的冲突点（关键）

dsh 上游**有意**将「仅思维链的 stop 视为成功」，且有测试固化：

- `dsh/packages/llm/llm-pi-ai/tests/convert.spec.ts:776`：
  - `'classifies a completed stop with no content as an EMPTY_RESPONSE error'` —— **零块** stop → `EMPTY_RESPONSE`（可重试码，见 `retry-policy.ts:19`）。
  - `'keeps a thinking-only stop successful (any block counts as content)'` —— **任意一块即算有内容**：`content:[{type:'thinking'}]` + stop → `{kind:'stop'}`（成功）。
- `packages/core/agent-loop/src/agent.ts:410-413`：`finish.kind === 'max-tokens'` 才特殊处理；否则**无 tool-call 即 `{kind:'completed'}`**——对「thinking-only stop」不设防。

因此本次退化形态（1 个 reasoning 块 + 谎报 stop）恰好落在上游刻意允许的语义里：
**不是上游疏漏，而是设计取舍与网关行为的组合结果**。直接收紧（见方案 a）会与该测试冲突，需上游决策。

## 4. 可选方案与取舍

- **方案 a：收紧为「必须有 text 或 tool-call 才算内容」**
  - 改动：`mapStopReason` 把「有块但无 text 且无 tool-call」的 stop 归入 EMPTY_RESPONSE；agent.ts:413 前加同类判定。
  - 代价：与 `convert.spec.ts:776` 显式设计冲突，需上游改测试语义；可能影响其它依赖 thinking-only 停止的调用方。
  - 折中变体：新增**配置开关**（如 `strictContentRequired`，默认 false 保持现语义），上游可选开启——兼容演进。

- **方案 b：保留现状，由调用方（harness/宿主）做退化检测与单案重跑**（本仓库已采用）
  - 检测签名：会话最后一次 assistant finish 为 `stop` 且 `replayState.blocks` 无 text 无 tool-call。
  - 优点：零跨项目影响、零上游依赖、可立即落地；重跑幂等（marker 窗口归因天然支持）。
  - 代价：重试有界（非框架层），且只作用于评测链路，不保护其它宿主。

- **方案 c：网关侧修复 / 更换模型**
  - pjlab 网关在限流/负载下应如实上报 `stopReason`（max-tokens 或 error），或至少不返回截断补全；属外部依赖，不在 dsh 控制内。
  - 换模型：规避该网关行为，但牺牲现有定标模型（glm-5.3），代价大。

## 5. 推荐

**采用方案 b**（本仓库 harness 侧退化检测 + 单案重跑，已由项目经理实现），并**向上游同步提案 (a) 的配置开关变体**：

- b 是唯一零风险、零跨项目影响的即时修复——上游「any block counts as content」是固化测试，本地改 dsh 会破坏与 MatDiscovery 等共用方的一致性；
- 时间线上 b 先兜底，上游若认可 (a) 开关变体，后续再优雅化；
- c 作为长期运营侧动作（与 pjlab 反馈网关行为），不作代码依赖。

附：本仓库重跑检测的具体签名（供上游参考实现 (a) 时的判定标准）——
`finish.reason.kind == "stop"` 且 `replayState.blocks` 不含 `text` / `tool-call`（仅 `reasoning`/`thinking`）。
